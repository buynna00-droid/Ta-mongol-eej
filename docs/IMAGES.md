# Зураг солих заавар

Албан ёсны зураг ороогүй хэсэгт **Unsplash-ийн түр (placeholder) зураг** харагдана.
Эдгээр нь "Та Монгол Ээж"-тэй ямар ч холбоогүй бөгөөд зарим нь хоорондоо давхардсан.
Албан ёсны зургаар солиход давхардал арилна. Аль хэсэгт ямар зураг ашиглагдаж буйг
`npm run build`-ийн тайлан харуулна ([5](#5-шалгах)).

Зураг солихын тулд кодыг засах шаардлагагүй: зургаа `public/images/` хавтсанд доорх
нэрээр хуулахад л хангалттай.

## 1. Зургийн эх сурвалж ба зөвшөөрөл

- Зөвхөн байгууллагын албан ёсны Facebook хуудас
  (<https://www.facebook.com/TaMongolEej>) дээр нийтлэгдсэн, эсвэл байгууллагаас өгсөн,
  **вэбсайтад нийтлэх зөвшөөрөлтэй** зургийг ашиглана.
- Facebook-ээс татсан зураг ихэвчлэн шахагдсан, жижиг хэмжээтэй байдаг. Боломжтой бол
  анхны (эх) файлыг байгууллагаас авна.
- Зурагт буй хүмүүсийн, ялангуяа **хүүхдийн хувьд эцэг эхийнх нь зөвшөөрлийг** заавал авна.
- Байгууллагатай холбоогүй stock зургийг албан ёсны зураг мэт бүү ашигла.

## 2. Файлын нэр ба хэмжээ

| Хэсэг | Файлын нэр | Санал болгох хэмжээ |
|---|---|---|
| Нүүр хэсэг (hero) | `hero.jpg` | 2000–2400 px өргөн, хэвтээ, ≤ 450 KB |
| Нүүр хэсэг — утсанд *(заавал биш)* | `hero-mobile.jpg` | 1000×1400 px, босоо, ≤ 250 KB |
| Бидний тухай | `about.jpg` | ≈ 1100×1300 px, босоо, ≤ 300 KB |
| Уур амьсгалын туузан зураг | `atmosphere.jpg` | 2000–2400 px өргөн, хэвтээ, ≤ 450 KB |
| Уур амьсгал — утсанд *(заавал биш)* | `atmosphere-mobile.jpg` | 1000 px өргөн, ≤ 200 KB |
| Ээжүүдийн сэтгэгдэл | `testimonial.jpg` | ≈ 1000×1100 px, ≤ 300 KB |
| Зургийн цомог 01 «Хайр дүүрэн мөч» | `gallery-1.jpg` | ≈ 900×750 px, ≤ 250 KB |
| Зургийн цомог 02 «Гэр бүлийн үнэ цэн» | `gallery-2.jpg` | ≈ 900×750 px, ≤ 250 KB |
| Зургийн цомог 03 «Хамтдаа өсөхүй» | `gallery-3.jpg` | ≈ 900×750 px, ≤ 250 KB |

- Өргөтгөл: `.jpg`, `.jpeg`, `.webp` эсвэл `.png` (том/жижиг үсэг хамаагүй).
  Нэг хэсэгт хэд хэдэн өргөтгөлтэй файл байвал `.webp`-г сонгож, анхааруулга өгнө.
- **Хэсэг бүрд өөр зураг** ашиглана. Нэг ижил зургийг хоёр газар тавибал build анхааруулна.
- `*-mobile` хувилбар нь зөвхөн үндсэн зураг (`hero.jpg` / `atmosphere.jpg`) байгаа үед
  ашиглагдана. Утасны дэлгэц (≤ 760 px) дээр үндсэн зургийн оронд харагдана.
- Нүүр хэсгийн зурагт гол дүр (нүүр царай) голдоо байвал утсан дээр сайн тайрагдана.

## 3. Зургийг вебэд зориулж шахах

Том файл сайтыг удаашруулна. Үнэгүй <https://squoosh.app> хэрэгслээр (зураг таны
браузер дотор боловсруулагдана):

1. Зургаа чирж оруулна.
2. **Resize** — дээрх хүснэгтийн өргөнийг тохируулна.
3. Формат: **MozJPEG** (Quality 75–82) эсвэл **WebP** (Quality 75–80).
4. Хэмжээ нь хүснэгтэд заасан хязгаараас бага болсныг шалгаад татаж авна.
5. Файлыг дээрх нэрээр нь `public/images/` хавтсанд хуулна.

Шахаагүй эх файлаа `originals/` хавтсанд хадгалж болно. Энэ хавтас сайтад орохгүй,
git-д ч commit хийгдэхгүй.

## 4. Alt текстийг шинэчлэх

Зураг бүрийн `alt` текст (хараагүй хүмүүст уншигддаг тайлбар) `src/config/images.js`
файлд байна. Зураг солих бүрд тухайн хэсгийн `alt`-ийг **зургийн бодит агуулгаар**,
монголоор, нэг өгүүлбэрээр засна. Жишээ:

```js
about: {
  file: 'about',
  alt: 'Ээжүүд ширээ тойрон сууж, хүүхдийн хүмүүжлийн талаар ярилцаж буй нь',
  …
}
```

Одоо бичигдсэн `alt` нь ерөнхий тайлбар тул бодит зурагт тохирохгүй байж магадгүй.

## 5. Шалгах

`npm run build` (эсвэл `npm run dev`) ажиллуулахад дараах тайлан гарна:

```
[зураг] public/images/: 3/7 албан ёсны зураг олдлоо. Бусад хэсэгт түр зураг (placeholder) харагдана — docs/IMAGES.md
  ✓ hero         public/images/hero.jpg (412 KB)
  ○ about        түр зураг (placeholder) — public/images/about.jpg нэмж солино
  …
  ⚠ …анхааруулга…
```

- `✓` — албан ёсны зураг ашиглагдаж байна, `○` — түр зураг хэвээр байна.
- `⚠` анхааруулгыг (хэт том файл, давхардсан зураг, танигдаагүй файлын нэр гэх мэт) засна.
- `npm run dev` ажиллаж байхад зураг нэмэх/солиход хуудас автоматаар шинэчлэгдэнэ.
- Зураг солих бүрд хаяг дахь `?v=…` тэмдэглэгээ өөрчлөгддөг тул зочдын браузер шинэ
  зургийг шууд татна.

Зургаа нэмсний дараа өөрчлөлтөө commit хийж, дахин deploy хийнэ.
