# Шалгалтын тайлан — 2026-11-23

Facebook автомат синкийг хэрэглэгчийн хүсэлтээр хассан. Серверийн API, token тохиргоо, синкийн компонент устсан. Facebook panel нь шууд холбоостой, About хэсэг өмнөх зургийн тохиргоогоо ашиглана. Доорх нь өмнөх шалгалтын түүхэн тайлан.

## Шалгасан ба өөрчилсөн файлууд

`src/App.jsx`, `src/styles.css`, `src/main.jsx`, `src/components/` дахь гурван компонент,
`src/config/`, `src/lib/`, `plugins/site-images.js`, Vite тохиргоо, `index.html`,
`package.json`, `.env.example`, `.gitignore`, README болон зургийн зааврыг шалгав.

Энэ удаагийн өөрчлөлт:
- `src/lib/formspree.js`: зөвхөн HTTP амжилттай бөгөөд JSON `ok: true` үед амжилт гэж үзнэ.
- `src/lib/formspree.test.js`: баталгаагүй хариу болон үйлчилгээний алдааны регрессийн тест.
- `src/App.jsx`, `src/styles.css`: цонх нээлттэй үед арын гүйлгэлтийг түгжиж,
  одоогийн жишээ сэтгэгдлүүдийг ил тод тэмдэглэв. Байрлал, өнгө, слайдерыг хадгалав.
- `plugins/site-images.js`, `docs/IMAGES.md`: файл олдсоныг албан ёсны эх сурвалжийн
  баталгаа гэж нэрлэхгүй болгосон.
- `README.md`, энэ тайлан: шалгалт ба үлдсэн ажлууд.

## Гүйцэтгэсэн шалгалт

- `npm run build`: амжилттай.
- `npm run build -- --base=./`: GitHub Pages-ийн харьцангуй замтай build амжилттай.
- `node --test src/lib/formspree.test.js`: 2 тест амжилттай. Бодит сүлжээ ашиглаагүй.
- Браузерын 1440, 1024, 768, 390, 360 px өргөнтэй тусдаа iframe хүрээнд DOM хэмжилт
  хийв: хуудасны хажуугийн халилтгүй, Facebook iframe багтсан. Preview resize бодит
  viewport-ийг өөрчлөхгүй байсан тул хүрээ ашигласан; төхөөрөмжийн бүрэн эмуляц биш.
- Дотоод холбоосуудын бүх target байна. Утасны цэс нээгдэж, холбоос дарахад хаагдсан.
- Гурван дэлгэрэнгүй цонх нээгдэж, focus шилжиж, Escape-аар хаагдсан. Арын гүйлгэлт
  түгжигдсэн. Утасны хэмжээнд цонх багтаж, хаах товч ажилласан.
- Слайдер дараагийн болон өмнөх сэтгэгдэл рүү шилжсэн.
- Хоосон маягтын 3 шаардлагатай талбарын алдаа гарч, эхний талбарт focus шилжсэн.
- Браузерт тусгаарласан маягт, орлуулсан fetch ашиглан тохиргоо дутуу мэдэгдэл,
  loading, давхар хүсэлтээс хамгаалалт, амжилтын мессеж, Messenger холбоос,
  дахин ижил бүртгэл илгээхээс хамгаалалтыг шалгав. Нэг хүсэлт л үүссэн.
  **Энэ нь Formspree рүү бодит бүртгэл илгээсэн туршилт биш.**

## Баталгаажаагүй зүйлс, үлдсэн тохиргоо

- Браузерын snapshot хэрэгсэл timeout болон screenshot frame алдаа өгсөн.
  Бүх хэсгийн дүрслэл, browser console, Facebook-ийн бодит feed-ийг бүрэн шалгасан гэж үзэхгүй.
- Facebook URL, lazy loading, title, container хэмжилт, шууд хуудас нээх fallback код байна.
  Бодит нийтлэл харагдах эсэхийг эзэмшигч браузерт шалгана.
- Formspree: код бэлэн, бодит endpoint байхгүй. `VITE_FORMSPREE_ENDPOINT` тохируулж,
  Submissions болон и-мэйлд туршилтын бүртгэл ирснийг баталгаажуулна.
- Цомог: script давхардуулахгүй loader, cleanup, fallback бэлэн. SociableKit / Elfsight
  embed код байхгүй тул автомат синхрончлол туршаагүй. `VITE_GALLERY_EMBED_CODE` шаардлагатай.
- Шинээр зураг солиогүй. Өмнөх `public/images/hero.webp` (ойролцоогоор 315 KB) байна;
  бусад 6 хэсэг Unsplash түр зурагтай хэвээр. Нүүр зураг нь уран зураг гэж alt-д
  тайлбарлагдсан. Бодит албан ёсны гэрэл зургийн шаардлагыг хангаж буйг батлаагүй.
- Нийтлэх зөвшөөрөлтэй 6 ялгаатай зураг болон бодит сэтгэгдлүүдийг эзэмшигч өгнө.

Статик build-ийг Vercel, Netlify, GitHub Pages-д байрлуулах боломжтой.
Бодит бүртгэл, автомат цомог, эцсийн контентыг идэвхжүүлэх дээрх ажил үлдсэн.
