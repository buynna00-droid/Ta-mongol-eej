"Та Монгол Ээж" нэгдлийн танилцуулга вэбсайт. React 18 + Vite 6 + Lucide React дээр
бүтсэн статик сайт. Facebook-ийн автомат синкийг хассан.
Vercel, Netlify, GitHub Pages-д байршуулна. Тусдаа сервер, database шаардлагагүй.
(Tailwind CSS-ийн тохиргоо төсөлд байгаа
ч загвар бүхэлдээ `src/styles.css`-д бичигдсэн.)

## 1. Хурдан эхлэх

Шаардлага: [Node.js](https://nodejs.org) 20 буюу түүнээс дээш (22 LTS санал болгоно).

```bash
npm install        # хамаарлуудыг суулгана (нэг удаа)
npm run dev        # хөгжүүлэлтийн сервер → http://localhost:5173
npm run build      # production build → dist/ хавтас
npm run preview    # build-ийг локалд үзэх → http://localhost:4173
```

`npm run dev` болон `npm run build` эхлэхэд аль хэсэгт албан ёсны зураг, аль хэсэгт түр
зураг ашиглагдаж буйг харуулсан `[зураг] …` тайлан гарна (→ [4](#4-зураг-солих)).

## 3. Тохиргоо (environment variables)

| Хувьсагч | Зориулалт | Хэлбэр |
|---|---|---|
| `VITE_FORMSPREE_ENDPOINT` | Бүртгэлийн маягт илгээгдэх Formspree хаяг | `https://formspree.io/f/YOUR_FORM_ID` |
| `VITE_GALLERY_EMBED_CODE` | SociableKit эсвэл Elfsight-ийн embed код | `'<div …></div><script src="https://…"></script>'` |

- **Локал:** `.env.example`-г `.env` нэрээр хуулж, утгуудаа оруулаад `npm run dev`-ээ дахин эхлүүлнэ.
- **Vercel / Netlify / GitHub Pages:** тухайн үйлчилгээний Environment Variables хэсэгт
  оруулаад дахин deploy хийнэ ([8](#8-deploy-vercel-netlify-github-pages)).
  Утга build хийх үед сайтад шингэдэг тул утга өөрчилсөн бүрд дахин deploy хийх шаардлагатай.
- ⚠ `VITE_` угтвартай утгууд вэбсайтын JavaScript-д шингэж, **хэн ч харах боломжтой**.
  Нууц үг, API түлхүүр бүү оруул. `.env` файл `.gitignore`-д орсон тул commit хийгдэхгүй.
- **Тохируулаагүй үед** сайт эвдрэхгүй:
  - маягт мэдээллийг **илгээхгүй**, харин "Онлайн бүртгэл одоогоор идэвхжээгүй байна…"
    гэсэн мэдэгдэл ба Messenger-ийн холбоос харуулна (амжилттай илгээсэн мэт хэзээ ч харуулахгүй);
  - зургийн цомгийн доор "Facebook-ээс үзэх" товч харагдана.
  - `npm run dev` горимд хөгжүүлэгчид зориулсан нэмэлт тайлбар харагдана (production-д харагдахгүй).

## 4. Зураг солих

1. Албан ёсны, нийтлэх зөвшөөрөлтэй зургаа вебэд зориулж шахна (≤ 250–450 KB).
2. `public/images/` хавтсанд дараах нэрээр хуулна:
   `hero.jpg`, `about.jpg`, `atmosphere.jpg`, `testimonial.jpg`, `gallery-1.jpg`,
   `gallery-2.jpg`, `gallery-3.jpg` (утсанд зориулсан `hero-mobile.jpg`,
   `atmosphere-mobile.jpg` — заавал биш).
3. `src/config/images.js` дахь `alt` текстийг зургийн бодит агуулгаар засна.
4. `npm run build` → тайланд `✓` гарч буйг шалгаад commit, deploy хийнэ.

Олдохгүй байгаа зураг түр (placeholder) зургаараа үлдэнэ. Хэмжээ, тайралт, шахалт,
зөвшөөрлийн талаар дэлгэрэнгүйг **[docs/IMAGES.md](docs/IMAGES.md)**-ээс уншина уу.

> Албан ёсны зураг ороогүй хэсэгт байгууллагатай холбоогүй Unsplash-ийн түр зураг харагдана.
> Аль хэсэг солигдсоныг `npm run build`-ийн `[зураг]` тайлангаас харна.

Facebook panel нь албан ёсны хуудас руу орох энгийн холбоос бүхий хэсэг.

## 6. Зургийн цомгийн виджет (хуучин лавлагаа)

Доорх SociableKit / Elfsight компонент болон заавар хадгалагдсан боловч одоогийн
хуудсанд ашиглагдахгүй. `VITE_GALLERY_EMBED_CODE` тохируулсан ч автомат синк эхлэхгүй.
Үндсэн гурван зурагтай цомог нь дотоод зургийн тохиргоогоо ашиглана.
**1) Виджет үүсгэх** (цэсийн нэрс үйлчилгээ шинэчлэгдэхэд өөрчлөгдөж болно)

- **SociableKit** (<https://www.sociablekit.com>) — бүртгүүлээд Facebook хуудасны зураг
  (page photos / albums) виджет үүсгэнэ.
- **Elfsight** (<https://elfsight.com>) — Facebook Feed эсвэл зургийн цомгийн виджет үүсгэнэ.
- Эх сурвалж: `https://www.facebook.com/TaMongolEej`
- Widget-ийн самбарт **Carousel / Slider**, бүх дэлгэцэд **нэг зураг**, touch swipe
  асаалттай, pagination dots болон өмнөх/дараах сумтай тохируулна. Автоматаар зураг
  солихыг унтрааж, зөвхөн зочин шударч эсвэл товч дарж солино. Харин Facebook-ийн
  шинэ зураг татах синхрончлолыг асаана. Зөвхөн зурагтай нийтлэл сонгож, текст,
  likes/comments, share, author/header-ийг нууна. Фон `#FAF7F2`, гол өнгө `#9E7B62`,
  булангийн дугуйлалт 24 px; зураг нэг ижил 4:5 харьцаатай байхаар тохируулна.
- Сонгосон үйлчилгээ/багц эдгээр боломжийг дэмжих эсэхийг embed авахаас өмнө шалгана.
  Сайт гаднын iframe доторх layout, swipe-ийг хүчээр өөрчлөх боломжгүй тул эдгээрийг
  үйлчилгээний самбарт тохируулах шаардлагатай. Бодит embed-гүй үед автомат зураг
  таталт болон swipe ажиллагаа идэвхжээгүй, туршигдаагүй.
- Үнэгүй багцад тоо хэмжээний хязгаар эсвэл үйлчилгээний лого гарч болзошгүй —
  үнийн нөхцөлийг тухайн сайтаас шалгана уу.

**2) Embed кодыг хуулж, ОРУУЛАХ байршил** — аль нэгийг сонгоно:

- **(санал болгох)** `VITE_GALLERY_EMBED_CODE` хувьсагчид кодыг бүтнээр нь (div + script)
  нэг мөрөнд оруулна. Локалд `.env` файлд, сайт дээр Vercel/Netlify-ийн Environment
  Variables-д. Хашилтын дүрмийг `.env.example`-ээс харна уу.
- эсвэл `src/config/site.js` → `GALLERY_EMBED_CODE_FALLBACK`-ийн хоёр backtick (`` ` ``)
  тэмдгийн хооронд шууд paste хийгээд commit хийнэ. (Embed код нь сайтын эх кодонд
  ил харагддаг тул нууц мэдээлэл биш.)

**3) Анхаарах**

- Script-ийг `index.html`-д тусад нь **бүү** нэм. Компонент нь script-ийг нэг л удаа,
  зочин цомог руу ойртох үед ачаална.
- Аюулгүй байдлын үүднээс зөвхөн `sociablekit.com`, `elfsight.com`, `elfsightcdn.com`
  домэйны **https** script хүлээн авна. Бусад код ашиглагдахгүй бөгөөд шалтгааныг
  `npm run dev` горимд хуудсан дээр, мөн браузерын консолд харуулна.
- Виджет ачаалж байх үед "Зургийн цомгийг ачаалж байна…", 15 секундэд харагдахгүй эсвэл
  script ачаалагдаагүй бол "Зургийн цомгийг ачаалж чадсангүй" гэсэн мэдэгдэл ба
  Facebook-ийн холбоос гарна.
- Кодоо оруулсны дараа deploy хийсэн сайтаа утас болон компьютер дээр нээж, цомог
  харагдаж буйг заавал шалгана уу.

## 7. Бүртгэлийн маягт (Formspree)

Маягтын талбарууд: **Эцэг/эхийн нэр**, **Утасны дугаар**, **Сонгох чиглэл** (Судар, ном /
Ардын ухаан / Сургалт), **Нэмэлт мэдээлэл**. Илгээгдсэн бүртгэл Formspree-ээр дамжин
байгууллагын и-мэйлд ирж, Formspree-ийн самбарт хадгалагдана.

**Тохируулах алхам**

1. <https://formspree.io> дээр байгууллагын и-мэйлээр бүртгүүлж, и-мэйлээ баталгаажуулна.
2. **New form** үүсгэнэ (жишээ нь: "Та Монгол Ээж — бүртгэл"), хүлээн авах и-мэйлийг сонгоно.
3. Form-ийн endpoint-ийг (`https://formspree.io/f/…`) хуулж `VITE_FORMSPREE_ENDPOINT`-д
   оруулна ([3](#3-тохиргоо-environment-variables)). Кодонд шууд бичих шаардлагагүй.
4. Form-ийн тохиргооноос **reCAPTCHA-г унтраана**. Энэ сайт маягтыг хуудсаа орхилгүйгээр
   (AJAX) илгээдэг тул reCAPTCHA асаалттай үед илгээлт амжилтгүй болно — сайт үүнийг
   алдаа гэж харуулна. Спамаас нуугдмал "honeypot" (`_gotcha`) талбар хамгаална.
5. Deploy хийсний дараа өөрөө нэг туршилтын бүртгэл илгээж, Formspree-ийн
   **Submissions** болон и-мэйлд ирсэн эсэхийг шалгаад, туршилтын бүртгэлийг устгана.

**Илгээгдэх өгөгдөл:** `name`, `phone` (`+976 9911 2233` хэлбэрт хөрвүүлсэн), `topic`,
`message`, `_subject` ("Шинэ бүртгэл: <чиглэл> — <нэр>"), `_gotcha`.

**Маягтын ажиллагаа**

- Талбар бүрийг монгол хэл дээрх тодорхой алдааны мессежээр шалгана. Утасны дугаарыг
  `9911 2233`, `9911-2233`, `+976 9911 2233`, `(+976) 9911 2233`, `00976…` гэх мэт
  хэлбэрээр хүлээн авна; гадаадын дугаарыг `+` тэмдэгтэйгээр (8–15 орон).
- Илгээж байх үед товч идэвхгүй болж "Илгээж байна…" гэж харагдана; давхар дарах,
  Enter дахин дарахад зөвхөн нэг хүсэлт явна.
- Ижил нэр + утас + чиглэлтэй бүртгэлийг 30 минутын дотор (тухайн браузерын цонхонд)
  дахин илгээхээс сэргийлнэ. Хувийн мэдээлэл биш, зөвхөн hash хадгална.
- Амжилттай бол: "Таны бүртгэл амжилттай илгээгдлээ. Бид тантай удахгүй холбогдох болно!"
  ба Messenger-ийн товч.
- Сүлжээ тасарсан, сервер хариу өгөөгүй (20 секунд), хэт олон удаа илгээсэн (429),
  Formspree татгалзсан, endpoint тохируулаагүй зэрэг тохиолдолд тус бүрдээ монгол
  мессеж ба Messenger-ийн холбоос харуулна. Амжилтыг **зөвхөн** Formspree баталгаажуулсан
  үед харуулна.
- Formspree-ийн үнэгүй багц сард хүлээн авах бүртгэлийн тоо хязгаартай (энэ баримтыг
  бичих үед сард 50) — нөхцөл өөрчлөгдөж болох тул <https://formspree.io/plans>-аас шалгана уу.
- Formspree бол гуравдагч талын үйлчилгээ; бүртгэлийн мэдээлэл тэдний серверт хадгалагдана.

## 8. Deploy: Vercel, Netlify, GitHub Pages

Бүх тохиолдолд: build command **`npm run build`**, гаралтын хавтас **`dist`**.
Орчны хувьсагчдыг build хийхээс **өмнө** оруулсан байх ёстой.

### Vercel

1. Төслөө GitHub (эсвэл GitLab/Bitbucket) repository руу push хийнэ.
2. <https://vercel.com> → **Add New… → Project** → repository-оо сонгоно.
   Framework Preset: **Vite** (автоматаар танина), Build Command: `npm run build`,
   Output Directory: `dist`.
3. **Environment Variables** хэсэгт `VITE_FORMSPREE_ENDPOINT` болон (бэлэн бол)
   `VITE_GALLERY_EMBED_CODE`-ийг нэмнэ.
4. **Deploy**. Дараа нь утга өөрчилбөл Deployments → **Redeploy** хийнэ.

### Netlify

1. <https://app.netlify.com> → **Add new site → Import an existing project** → repository-оо сонгоно.
2. Build command: `npm run build`, Publish directory: `dist`.
3. **Site configuration → Environment variables** хэсэгт дээрх хувьсагчдыг нэмнэ.
4. **Deploy**. Дараа нь утга өөрчилбөл **Deploys → Trigger deploy** хийнэ.

### GitHub Pages

GitHub Pages сайтыг `https://<хэрэглэгч>.github.io/<repository>/` гэсэн дэд хаягаар
нийтэлдэг тул build-ийг харьцангуй замтай хийнэ:

```bash
npm run build -- --base=./
```

- `dist/` хавтасны агуулгыг GitHub Actions-оор нийтэлнэ: Settings → Pages → Source:
  **GitHub Actions**. Workflow-ийн жишээ: [Vite — GitHub Pages](https://vite.dev/guide/static-deploy#github-pages)
  (build алхмыг `npm run build -- --base=./` болгоно).
- `.env` файл GitHub дээр байхгүй тул утгуудыг Settings → Secrets and variables →
  Actions → **Variables**-д нэмж, workflow-ийн build алхамд `env:`-ээр дамжуулна.
- Windows-ийн Git Bash дээр `--base=/нэр/` хэлбэрийн аргумент замын хувиргалтад өртдөг
  тул дээрх `--base=./` хэлбэрийг ашиглана уу.
